# DSG Liga - Premium Vanilla HTML/CSS Aesthetic Mandate

## 1. The Core Philosophy
This project STRICTLY prohibits generic, outdated "MVP" layouts, default browser styling, and heavy frameworks like Tailwind or React. We are building a visually stunning, premium web application using Vanilla HTML, CSS, and plain JavaScript.

## 2. Design System & Typography
- **Typography:** Use modern sans-serif fonts (e.g., Inter, Roboto, or Outfit) for a clean, athletic, professional look. 
- **Color Palette:** Curate a harmonious, vibrant color palette that fits an amateur football league but feels like a top-tier professional sports platform. 
- **Theme:** Utilize sleek dark modes or clean glassmorphism patterns to create depth and modernity.

## 3. Micro-Animations & Interactivity
- **Hover States:** Every interactive element (buttons, cards, navigation links, table rows) MUST have dynamic, smooth CSS transitions (e.g., `transition: all 0.3s ease`).
- **Scroll Effects:** Implement subtle fade-ins, slide-ups, and staggered animations for content as it enters the viewport. Use Anime.js for complex orchestration.
- **Feedback:** Provide immediate, satisfying visual feedback for user actions (clicks, form submissions).

## 4. Layout & UI Patterns
- **Modern Grid/Flexbox:** Use CSS Grid and Flexbox for responsive, fluid layouts. No table-based layouts for structure.
- **Cards & Containers:** Use subtle translucent backgrounds with `backdrop-filter: blur()` (Glassmorphism) or soft neuromorphic shadows.
- **Data Visualization:** League tables and statistics must be designed with premium UI patterns—clear hierarchy, badges for team logos, and modern spacing.

## 5. Dashboard Aesthetics
- The Admin Dashboard must be as beautiful as the public site. It should feature an intuitive layout, sleek custom form inputs, and animated success/error states. 

## 6. Execution Rules for Subagents
- **ALWAYS** apply `design-spells`, `frontend-design`, and `animejs-animation` principles.
- **NEVER** output plain, unstyled HTML.
- **NEVER** use generic colors like `red`, `blue`, `green`. Use specific HSL or HEX codes tailored to the brand.
